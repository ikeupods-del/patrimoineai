# QuenTools : conventions communes
- Tout outil qui doit sauvegarder/synchroniser des données utilisateur utilise **Firebase (projet `quentools-adca1`)** : connexion Google + Firestore, données chiffrées côté navigateur. **Lire `docs/GUIDE-CONNEXION-GOOGLE-QUENTOOLS.md` avant de coder** (recette complète, config, limites).
- Chaque outil est une PWA statique sur GitHub Pages (workflow `.github/workflows/pages.yml`), avec la marque « Produit par QuenTools ».
- Répondre à l'utilisateur en français.

## Repères Patrimoine AI
- Une seule source pour le web et le Mac : `index.html` (+ `marches.js`, `calculs.js`, `config.js`, `vendor/`). L'application Mac (`mac/`, Electron) copie ces fichiers à la construction et ajoute le pont `window.patrimoineMac` (`mac/preload.js`) ; dans la page, `MAC` vaut ce pont (null dans le navigateur) : toute fonction propre au Mac se teste par `MAC`.
- Données : `D` (localStorage `pat_data`) ; catégories dans `CATS` (dont `bien` et `credit` : un crédit n'est jamais compté dans les actifs, `totals()` donne `tv` brut, `debt`, `net`, `fin`). Nouveaux champs : `D.budget`, `D.goals`, `D.alerts`, `D.target`, `D.ops` (opérations des relevés), `D.regles` (catégories apprises), `D.fire` (simulation retraite), `D.bank` (banque liée : comptes, soldes, échéance de l'accord), `D.rappels` (rappels de paiement, `hist` par mois) ; tout champ synchronisé doit être ajouté à `SF`, `payload()` et `mergeRemote()`. Restent locaux : `D.fx` (taux de change), `D.docs` (métadonnées du coffre, fichiers chiffrés dans IndexedDB `patrimoine-coffre`).
- Calculs sans affichage dans `calculs.js` (`window.Calculs`, `CL` dans la page) : lecture des relevés, catégories, abonnements, TRI, Monte-Carlo, fiscalité, revenus passifs ; testés par `node tests/calculs.test.js`. Devises : `a.dev` (+ `a.fxm`), conversion par `tauxDev(a)` dans `val()`/`inv()`. Versements datés : `a.mv` (rendement réel `flux(a)`).
- Écrans : `renderX()` + section `v-x` + `NAV`/`TITLES` ; actions `ACT['nom']` via `data-act`. Ne jamais redessiner un écran pendant une saisie (`typing()`).
- Cours : positions `bourse` avec ticker Yahoo suivies en direct (`liveSync`, `marches.js`) et actualisées (`refresh`) ; sans ticker, `autoTickers` le trouve d'après l'ISIN ou le nom (`CL.isinDe`, `CL.choisirTicker` : places européennes d'abord), marque `tickAuto`, nouvel essai une semaine après un échec (`tickEssai`).
- Variation du patrimoine (`bougeHTML`, `CL.variation` : points `D.hist` avec `k` dettes et `g` plus-values par catégorie), aide à la déclaration (`declData`/`declHTML`, onglet `decl` des Simulateurs, `CL.declaration` ; plus-values réalisées gardées dans `a.ventes` par `tradeSave`), frais cachés (`fraisHTML`, `CL.fraisPlacements`, `CL.fraisBancaires`) ; réponses de l'assistant local `aBouge`, `aDecl`, `aFrais`.
- IA du Mac : `macAnswer` (contrôle des chiffres `unknownNums`), modèle et code partagés avec Quentools (`mac/ia-locale.js`, `mac/ia-worker.js`, copies de `marketing/ia-locale/`).
- Liaison bancaire **dans l'application Mac, sans serveur ni Netlify** (choix du propriétaire : GitHub seulement) : routes `banque/routes/*.mjs` (+ `banque/` : accès, stockage, client Enable Banking, banque de démonstration) exécutées par `mac/banque-locale.js` (protocole `app://patrimoine/api/banque/…`, clé .pem et session chiffrées par le trousseau, retour de la banque par la page en ligne renvoyée vers `127.0.0.1:<port>` d'après le `state` `mac<port>-…`) ; la version en ligne reçoit soldes et opérations par la synchronisation ; test `node tests/banque-mac.js`, écran `renderBank` (`BQ`, `bqApi`), rappels `rap*` (calculs `CL.rappelsDus`, `CL.echeanceR` jours ouvrés, `CL.rapprocher`, `CL.retraitsPossibles`, `CL.ecarterDoublons`, `CL.opsBanque`, `CL.ics`), test de configuration `banque-diagnostic`. Mode d'emploi : `docs/BANQUE.md`. Aucune clé dans le dépôt.
- Données versionnées : `SCHEMA` et `migrate()` (index.html, étapes successives, `D.sv`). Rappels synchronisés un par un (`u`, suppressions dans `D.del`) et historique mois par mois (`t` de chaque validation) : `CL.fusionRappels`, `CL.fusionHist` ; validation annulée = `{s:'annule',t}` (`CL.traite`). Statuts `a_valider` / `retard` (J+3) / `alerte` (J+10). Échéanciers : `CL.echeancier` (`amort`, `infine`, `loyer`), `echMode`/`echOf` (champ `a.ech`), `rapPrevu`/`rapAttendu`, `CL.partCapital` ; historique et annulation `openRapHist`/`rapAnnuler` (trace `h.w` du portefeuille crédité) ; notifications par le service worker (`notify`, `rapPublier` → cache `patrimoine-etat`, `periodicsync` et `push` dans `sw.js`) ; intention `rappel` de l'IA locale (`aRappel`), `rappels_versements` et `echeanciers` dans `dossier()`.
- Avant de livrer : `node tests/marches.test.js`, `node tests/calculs.test.js`, `node tests/banque.test.js`, `node tests/e2e.js`, `node tests/banque-e2e.js` et `node tests/banque-mac.js` (audit d'accessibilité : `AXE=…/axe.min.js`) ; pour l'application Mac, nouvelle version = `mac/package.json` + `mac/NOUVEAUTES.md` (le workflow construit, essaie et publie).
