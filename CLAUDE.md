# QuenTools : conventions communes
- Tout outil qui doit sauvegarder/synchroniser des données utilisateur utilise **Firebase (projet `quentools-adca1`)** : connexion Google + Firestore, données chiffrées côté navigateur. **Lire `docs/GUIDE-CONNEXION-GOOGLE-QUENTOOLS.md` avant de coder** (recette complète, config, limites).
- Chaque outil est une PWA statique sur GitHub Pages (workflow `.github/workflows/pages.yml`), avec la marque « Produit par QuenTools ».
- Répondre à l'utilisateur en français.

## Repères Patrimoine AI
- Une seule source pour le web et le Mac : `index.html` (+ `marches.js`, `calculs.js`, `config.js`, `vendor/`). L'application Mac (`mac/`, Electron) copie ces fichiers à la construction et ajoute le pont `window.patrimoineMac` (`mac/preload.js`) ; dans la page, `MAC` vaut ce pont (null dans le navigateur) : toute fonction propre au Mac se teste par `MAC`.
- Données : `D` (localStorage `pat_data`) ; catégories dans `CATS` (dont `bien` et `credit` : un crédit n'est jamais compté dans les actifs, `totals()` donne `tv` brut, `debt`, `net`, `fin`). Nouveaux champs : `D.budget`, `D.goals`, `D.alerts`, `D.target`, `D.ops` (opérations des relevés), `D.regles` (catégories apprises), `D.fire` (simulation retraite), `D.rappels` (rappels de paiement, `hist` par mois) ; tout champ synchronisé doit être ajouté à `SF`, `payload()` et `mergeRemote()`. Restent locaux : `D.fx` (taux de change), `D.docs` (métadonnées du coffre, fichiers chiffrés dans IndexedDB `patrimoine-coffre`).
- Calculs sans affichage dans `calculs.js` (`window.Calculs`, `CL` dans la page) : lecture des relevés, catégories, abonnements, TRI, Monte-Carlo, fiscalité, revenus passifs ; testés par `node tests/calculs.test.js`. Devises : `a.dev` (+ `a.fxm`), conversion par `tauxDev(a)` dans `val()`/`inv()`. Versements datés : `a.mv` (rendement réel `flux(a)`).
- Écrans : `renderX()` + section `v-x` + `NAV`/`TITLES` ; actions `ACT['nom']` via `data-act`. Ne jamais redessiner un écran pendant une saisie (`typing()`).
- Cours : positions `bourse` avec ticker Yahoo suivies en direct (`liveSync`, `marches.js`) et actualisées (`refresh`) ; sans ticker, `autoTickers` le trouve d'après l'ISIN ou le nom (`CL.isinDe`, `CL.choisirTicker` : places européennes d'abord), marque `tickAuto`, nouvel essai une semaine après un échec (`tickEssai`).
- Variation du patrimoine (`bougeHTML`, `CL.variation` : points `D.hist` avec `k` dettes et `g` plus-values par catégorie), aide à la déclaration (`declData`/`declHTML`, onglet `decl` des Simulateurs, `CL.declaration` ; plus-values réalisées gardées dans `a.ventes` par `tradeSave`), frais cachés (`fraisHTML`, `CL.fraisPlacements`, `CL.fraisBancaires`) ; réponses de l'assistant local `aBouge`, `aDecl`, `aFrais`. Import du portefeuille d'un courtier : `posLire`/`posApercu`/`posGo` (fenêtre Importer), `CL.lirePositions`, `CL.rapprocherPositions`.
- IA du Mac : `macAnswer` (contrôle des chiffres `unknownNums`), modèle et code partagés avec Quentools (`mac/ia-locale.js`, `mac/ia-worker.js`, copies de `marketing/ia-locale/`).
- **Liaison bancaire retirée** (novembre 2026, demande du propriétaire : plus d'Enable Banking, ni dans l'application Mac ni sur le web). Comptes suivis à la main ou par relevés importés ; `migrate()` étape 3 retire `D.bank` et `a.bq` (dernier solde gardé), les opérations reçues (`fid` `eb:…`) restent dans le budget. Écran des rappels = vue `bank` (nom historique, titre « Mes versements ») : `renderVersements`, rappels `rap*` (calculs `CL.rappelsDus`, `CL.echeanceR` jours ouvrés, `CL.ecarterDoublons`, `CL.ics`). Mode d'emploi : `docs/RAPPELS.md`. Fonctions serveur restantes (notifications push seulement) : `serveur/commun.mjs` (compte Google vérifié, chiffrement, CORS), adresse `srvBase()` (`serveurApi` dans config.js, `'aucun'` = jamais). Aucune clé dans le dépôt.
- Données versionnées : `SCHEMA` et `migrate()` (index.html, étapes successives, `D.sv`). Rappels synchronisés un par un (`u`, suppressions dans `D.del`) et historique mois par mois (`t` de chaque validation) : `CL.fusionRappels`, `CL.fusionHist` ; validation annulée = `{s:'annule',t}` (`CL.traite`). Statuts `a_valider` / `retard` (J+3) / `alerte` (J+10). Échéanciers : `CL.echeancier` (`amort`, `infine`, `loyer`), `echMode`/`echOf` (champ `a.ech`), `rapPrevu`/`rapAttendu`, `CL.partCapital` ; historique et annulation `openRapHist`/`rapAnnuler` (trace `h.w` du portefeuille crédité) ; notifications par le service worker (`notify`, `rapPublier` → cache `patrimoine-etat`, `periodicsync` et `push` dans `sw.js`) ; intention `rappel` de l'IA locale (`aRappel`), `rappels_versements` et `echeanciers` dans `dossier()`.
- Revenus passifs (écran `rev`, `renderRev`) : sources `revSources` (réel = `a.paie` hors capital et dividendes Yahoo ; prévu = échéanciers, taux, loyers), `revData` (gardé dans `REVC` jusqu'au prochain `render`), `CL.tableauRevenus` (`reel`, `prevu`, `suivi` = prévu des sources suivies, `estime` = sans suivi, et leurs `…Net`), `CL.rendements` (TRI brut et net par plateforme), fiscalité réglable `D.fisc` (synchronisée, `CL.fiscalite`, `CL.tauxImpot`, `openFisc`) ; intention `passif` (`aPassif`), `revenus_passifs` dans `dossier()`.
- Vue fiscale (onglet `decl` des Simulateurs) : `declData` → `CL.vueFiscale` (plateformes, `brutDe` selon `srcNet` = réglage `D.fisc.src` par plateforme, prélèvements retenus, `imputationPertes`, `comparerPfuBareme` partagé avec `calcTax`), pertes définitives `a.perte` (`openPerte`), cases et règles dans `fiscal-config.js` (`window.FISCAL_CONFIG`, `FCFG()`, certitude `courante`/`a_verifier` affichée par `CERT`), exports `declCSV` et `declPdfHTML` + `pdfDoc` (partagé avec le bilan). Nouveau fichier de l'application = `sw.js` (CORE), `pages.yml`, `mac/scripts/copier-app.js` et la liste de `mac.yml`.
- Import Finary / tableur (`openImpTab`, `impLire`, `impColonnes`, `impRappro`, `impAppliquer`, `impAnnuler`) : `CL.lireXLSX` (zip lu par `DecompressionStream`, sans bibliothèque), `CL.tableauImport`, `CL.devinerColonnes`, `CL.typeImport`, `CL.lignesImport`, `CL.rapprocherImport` (doublons, déjà à jour, établissement), capture → `gem` → `CL.tableauDepuisJSON` ; colonnes retenues `D.impMap` (synchronisé), annulation `D.impUndo` (local) ; intention `import` (`aImport`).
- Notifications push des rappels (facultatives, Netlify) : `push/push.mjs` (VAPID ES256 sans bibliothèque, `aPrevenir`, envoi sans contenu, `tournee`), routes `push/routes/`, fonctions `netlify/functions/push-*.mjs` + `rappels-push.mjs` (planifiée), clés `node push/cles-vapid.mjs` ; côté page `pushEtat`/`pushActiver`/`pushMaj`/`pushHTML` (`D.set.push`). Mode d'emploi et implications : `docs/PUSH.md`.
- Application installable : raccourcis et partage de fichiers dans `manifest.webmanifest` (`shortcuts`, `share_target` → POST `./partage` reçu par `sw.js`, cache `patrimoine-partage`), `actionDemarrage` (`?action=ajouter|importer|partage`). Affichage à la demande : `VUES` + `SALE` (seul l'écran visible est redessiné par `render`). Mois en toutes lettres avec élision : `deMois`.
- Version web sans Mac : verrouillage WebAuthn `VW` (`vwDemander`, `vwActiver`, `vwVerrouiller`, `vwOuvrir`, secours `vwSecours`, localStorage `pat_verrou`, réutilise `#lock` et `body.locked`), installation `INST`/`instHTML` (`beforeinstallprompt`, marche à suivre iPhone), « Retrouver mes données » dans `onboarding`.
- Avant de livrer : `node tests/marches.test.js`, `node tests/calculs.test.js`, `node tests/push.test.js`, `node tests/pwa.js`, `node tests/e2e.js` et `node tests/rappels-e2e.js` (audit d'accessibilité : `AXE=…/axe.min.js`) ; pour l'application Mac, nouvelle version = `mac/package.json` + `mac/NOUVEAUTES.md` (le workflow construit, essaie et publie).
